# An explicit workflow controls the write

Use a small state machine with typed steps, injected clocks and explicit budgets. Give the model extraction and explanation tasks.

## Context

A reviewer must be able to trace each external effect from the approval. A free-form tool loop would put the most important transition inside model behaviour.

## Consequences

Each transition is inspectable and testable. The project owns journal replay, deadlines and leases. A distributed deployment could move those mechanics into a workflow runtime.
